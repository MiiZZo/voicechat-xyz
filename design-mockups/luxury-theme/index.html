How to choose

All three concepts use the same zinc-240 palette from apps/client/tailwind.config.ts — they differ in typography, composition and texture, not in color. Velvet Onyx is the one shown with the full component library (call bar, icon-button states, buttons, inputs, selects, switches, sliders, tabs, participant tiles, toasts). The other two demonstrate the same call bar + buttons + inputs + icon states for direct comparison. None are wired to the app yet — tell me which direction (or which elements from which) and I'll add it as a real switchable theme in apps/client and apps/client-tauri.
